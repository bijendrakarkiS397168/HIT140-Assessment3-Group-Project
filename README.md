# HIT140 Assessment 3: World Cup 2026 regression

This repository holds the Python code, source data and results for Objective 2 of the HIT140 Foundations of Data Science group project. Objective 2 fits two multiple linear regression models on the 104 matches of the 2026 FIFA World Cup. Every predictor uses only information available before kick-off.

| Task | Question | Unit of observation | Rows | Response |
|---|---|---|---|---|
| 2.1 | What is the goal difference between two teams? | One match | 104 | `goals_a - goals_b` |
| 2.2 | How many goals does one team score? | One team in one match | 208 | Goals scored by that team |

Team A and team B follow ESPN's listed order. The order does not imply a home-ground advantage.

## Run the project

The project needs Python 3 with `numpy`, `pandas`, `scipy`, `scikit-learn`, `statsmodels` and `matplotlib`.

1. Download or clone the repository. GitHub's file view does not run Python.
2. Install the dependencies with `START_HERE.bat`, or run `pip install numpy pandas scipy scikit-learn statsmodels matplotlib`.
3. Run the scripts from the repository root:

```bash
python Avayash_Gaire_data.py                           # optional: rebuild data/raw from data/sources
python Bijendra_Karki_goal_difference.py --no-open     # Task 2.1
python Ritesh_Panta_goals_scored.py --no-open          # Task 2.2
```

Each task script validates `data/raw` and writes its outputs to `results/task_2_1` or `results/task_2_2`. Without `--no-open`, the script also opens the results viewer in a browser. The scripts are deterministic, so repeated runs give the same coefficients and metrics.

## Data

ESPN's public World Cup scoreboard feed supplies the match results. A pinned snapshot of Mart Jürisoo's CC0 international-results dataset (commit `b7a3a8ee`) supplies the earlier matches behind each feature, and it confirms the score of all 104 matches. Both sources were collected on 10 October 2026. `DATA_GUIDE.md` and `SOURCE_REVIEW.md` describe the sources, eligibility rules and cross-checks in full.

Three conventions apply throughout:

- A pre-match feature is computed from a team's last ten eligible senior international results. A result with only a date becomes eligible two UTC days after that date.
- Scores include extra time and exclude shootouts, for both responses and history-based predictors.
- No match result is inferred, and the predictors have no missing cells.

## Model design

Each model has eight predictors. Four underlying concepts appear in both models, the maximum the brief allows: goals scored, goals conceded, days since the last match and win rate.

Task 2.1 uses the difference between team A and team B for each of these:

- goals scored
- goals conceded
- win rate
- days since the last match
- matches in the last 365 days
- standard deviation of goal difference
- previous World Cup appearances
- host-country advantage

Task 2.2 uses four measures for the scoring team: goals scored, scoring rate, days since the last match and the standard deviation of goals scored. It uses four for the opponent: goals conceded, win rate, clean-sheet rate and draw rate.

The holdout is the last 20% of match days. Five forward folds within the earlier days are used for validation. Both team rows of a match always fall on the same side of a split. Each model faces a baseline that predicts the training mean.

## Results

The table shows the chronological holdout, generated by the scripts above.

| Task | Holdout size | Model | MAE | RMSE | R² |
|---|---|---|---:|---:|---:|
| 2.1 | 7 matches | Linear regression | 1.211 | 1.402 | 0.108 |
| 2.1 | 7 matches | Training mean | 1.503 | 1.690 | -0.295 |
| 2.2 | 7 matches (14 rows) | Linear regression | 1.127 | 1.646 | -0.125 |
| 2.2 | 7 matches (14 rows) | Training mean | 1.143 | 1.602 | -0.066 |

Task 2.1 beats the baseline on all three measures. Task 2.2 does not: its MAE is slightly lower, but its RMSE and R² are worse than predicting the training mean. Both tasks train on 96 matches (192 rows for Task 2.2). One further match is out of the split because its outcome was not yet known at the training cut-off. Coefficients, VIF, influence, residual diagnostics and plots are in each `results/task_*` folder.

## Limitations

- Sample size. With 104 matches and a holdout of seven, the metrics are unstable.
- Count response. Goals are non-negative counts, and linear regression can predict negative or fractional values. The Task 2.2 holdout produced no negative predictions.
- Collinearity. The Task 2.2 VIF output shows moderate multicollinearity. The team kept all eight predictors rather than dropping any to improve the fit.
- Association only. The coefficients describe statistical association, not cause.
- Retrospective features. The features are rebuilt from current source snapshots. The eligibility cut-offs are assumptions, not archived publication times.
- Extra time. The score definition includes extra time. The group must confirm this against the assignment brief.
