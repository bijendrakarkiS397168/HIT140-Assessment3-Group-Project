# GitHub upload guide for Kalyan Acharya

This folder is an upload bundle for your assigned role. All four bundles belong in ONE shared repository.

1. Extract this ZIP.
2. Open the Kalyan_Acharya folder in Windows File Explorer.
3. On the repository main page choose Add file > Upload files.
4. Drag the CONTENTS of this folder into GitHub, not the outer Kalyan_Acharya folder. Drag data, results or tests folders whole to preserve their paths.
5. Commit the upload using your own account after reviewing the files.

Do not flatten results/task_2_1 or results/task_2_2. Do not upload the ZIP itself, .venv or __pycache__.

The four bundles contain different parts of the same project. A member bundle alone is not a standalone application. After all four members upload, README.md, project.py, all four named scripts and START_HERE.bat must be at the repository main level; data, results and tests must be folders at that level.

Download the completed repository to run it. Install dependencies with START_HERE.bat or follow README.md. GitHub's file page does not execute Python or open the results dashboard as a website.

Role assignment is not proof of authorship. Record your actual reviewed work and AI assistance accurately.
